# Issue #58 — frozen historical B-mode OpenJij cross-host replay

**Protocol established before opening the new replay results.** This is a controlled **classical** simulated-annealing reproducibility test on the Laguna de Bay **notebook-derived** N20/K5 instance. Its base is the source-verified historical mode-B / B-penalty arm of [PR #27](https://github.com/carlers/quantum-opt-dashboard/pull/27) and the original paired 32×32 child-seed manifest of [issue #22](https://github.com/carlers/quantum-opt-dashboard/issues/22). The proposed *maintained* source-derived N20 notebook reference remains [draft PR #56](https://github.com/carlers/quantum-opt-dashboard/pull/56); independently measured source model IEEE754 differences are documented by [draft PR #57](https://github.com/carlers/quantum-opt-dashboard/pull/57).

## 1. Evidence basis, frozen choice and non-goals

- This protocol **deliberately freezes historical input mode B** — archived SCIP instance SHA `0718156034e83d46223fa3e4e086bc9997c16f7252e3c348ca8ac70cf19d5532`, the notebook-derived B local row-sum penalty exact hex `0x1.190ab5b15d1b3p+0`, full original quadratic terms and 20-variable local one-hop graph, and slack-encoded **46-variable / 323 nonzero QUBO terms** from `prototypes/streamlit_water_quality/qubo.py`. The historical B observation was 665 original-feasible and 13 exact-optimum samples per 1,024; do **not** treat this as a required new outcome, or relabel it as the published paper's QUBO.
- The old original A mode (698/1024) and controlled A/B coefficient/penalty sensitivity from [PR #27](https://github.com/carlers/quantum-opt-dashboard/pull/27) remain valid **separate archived evidence**. The one-ULP penalty difference already reproduced the historical sample swing within the controlled paired-seed experiment; this study is instead about cross-process/**cross-host bitstring repeatability of a truly identical QUBO**.
- **No new model build, QUBO conversion or penalty derivation may occur inside a sampler job**. A one-time fixture-generation script reuses `sa_ulp_replay.build_arms()` and the historical reference verifier, publishes the exact float.hex variable-indexed QUBO including offset, 323 coefficient pairs, full original MIQP coefficients/constraint mask and the **complete 1,024 child-seed integers**. This exact JSON is reviewed/committed and its file SHA hard-coded in the sampler verifier **before starting cross-host sampling**.
- The input is an exact **binary QUBO**, not an Ising/spin coupler list. `openjij.SASampler().sample_qubo(matrix, num_reads=1, num_sweeps=300, seed=<child seed>, sparse=True)`, with the original 32 parents from 270010001 through 270010032 (inclusive) and 32 `SeedSequence.spawn` children each, one sampler call per child. Keep original `num_sweeps`, `sparse` flag, returned binary labels, and index order.
- Execute three independent Ubuntu 24.04 GitHub-hosted runner jobs, **two distinct fresh Python processes per job** against exactly the same committed fixture. **1024 reads per process, six processes, total 6144 classical SA calls**. This is intentionally bounded to one preregistered penalty and original seed manifest; no new tuning, paid QPU, or adaptive seed search. Each host's two processes must agree on input digest, even if output bitstrings vary.
- Results: full **ordered** 46-bit sample vector for each read (including infeasible ones), parent + child seed and read index, independently computed original budget/one-hop feasibility and raw MIQP original energy, SCIP optimum hit flag within 1e-7, expanded QUBO energy+offset and OpenJij-reported energy with independent check against direct unexpanded squared-penalty expression. Save a canonical samples SHA and **all original 1024 vectors** per execution, not just counts.
- Compare original fixture SHA, read-seed list and OpenJij version across all runs, first 1024 sample-vector digests and read-by-read mismatch counts, original feasibility flag flips, feasible draw counts and optimum hit counts. Report each numeric/environment variable that may confound cross-host comparisons, including Python/NumPy/OpenJij versions and limited CPU/BLAS environment. No arbitrary environment-variable dump/secrets.
- All results are purely descriptive for one frozen lake instance and selected historical sampler configuration. No confidence intervals from individual child reads, no independent hypothesis test, no universal cross-host deterministic guarantee, no claim of quantum hardware or advantage, no publication parity.

## 2. Predefined acceptance and interpretation

1. The frozen fixture file SHA and internal canonical `qubo` digest must match **before** opening OpenJij. The generated candidate's hashes shall be recorded with the evidence and copied to the repo unmodified. Any mismatch **fails** the run; no new coefficient is calculated in a host job.
2. Deterministic toy QUBO test checks decoding/binary indexing/sampler-energy convention without relying on the lake optimizer. The real frozen problem must reproduce independent 15,504 N20 combinations / 1,077 originally feasible subsets / certified optimum local `[0,1,3,6,7]` and `-3.3012934918564643` under exact K=5 and **local**, not global, one-hop adjacency.
3. Every returned OpenJij state must contain exactly the 46 expected binary indices; `num_occurrences=1` for each independently seeded one-read call. Verify both QUBO expansion and original direct feasibility/objective independently for every state; include infeasible reads in denominator.
4. If full bitstrings match across all six processes, report **“observed cross-host bitwise equality on the 6 checked process runs”**, not a universal stochastic API guarantee. If any differ, report read-index/child seed, full mismatch vectors, energy/feasibility differences, package/environment/host metadata; **identical frozen inputs permit investigating sampler/runtime nondeterminism**, not claiming it without ruling out other changes.
5. Any code fix after results must be recorded in GitHub history and rerun from exact input SHA. Preserve positive/negative outcomes; do **not** alter the historical A/B observations, retune source coefficients or penalties, or cherry-pick favorable hosts.
6. GitHub Actions artifacts retain raw files for 14 days; copy checksum-verified study results to durable restricted research storage before expiry where rights permit. Do not include secret tokens or unlicensed new data.

## 3. Source and review boundaries

All new code resides in a dedicated **stacked PR**, based on old historical reference PR #27 because that branch contains the *actual original experimental QUBO encoder and seed schedule*. It is scientifically cross-referenced to the modern clean N20 notebook PR #56 and float64 probe PR #57, but no merge, port, deployment, original manuscript/notebook/GeoJSON modification is authorized. Any generalized solver API, new research experiment, model normalization, or production/dashboard integration requires a **separate** review.

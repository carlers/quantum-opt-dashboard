## Scientific conclusion and remaining limits

1. **This fixed exact B/B QUBO is reproducible bitwise in the observed six fresh processes across the observed AMD EPYC 7763/9V45 hosts**, with fixed software/thread controls. The historical original B archive also agrees exactly for all audited fields.
2. Combined with the *earlier* [controlled four-arm #26 / PR #27](https://github.com/carlers/quantum-opt-dashboard/pull/27) experiment, the data support the mechanism **candidate-17 last-bit linear drift → one-ULP change in derived notebook row-sum penalty → different classical OpenJij sample paths** *under those previously controlled seeds and binaries*. PR #27 found penalty-only variation changed **882/1024 entire sampled states** and **363 original feasibility flags**, producing net +33 feasible results, while coefficient-only variations at fixed penalty altered **0/1024 states**. We did not redo or retune that experiment here.
3. **Still open:** why/where at exact arithmetic/geometric operation level the original notebook-derived free–fixed candidate-17 coefficient varied across host processes (see #24 and #57). This study also does not demonstrate all future CPU architectures/versions/parallel configurations must return equal states, establish quantum-hardware results, recreate published Table V or establish inference across real-world lakes.
4. No original manuscript/notebook/GeoJSON, historical pre-registered sample files, lake mathematical model, \`main\`, preview or deployed Streamlit pilot changed. [Draft PR #59](https://github.com/carlers/quantum-opt-dashboard/pull/59) requires human scientific review and separate explicit authorization before any merge/deployment.

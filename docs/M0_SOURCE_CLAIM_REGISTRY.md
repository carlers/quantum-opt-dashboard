## Computed optimality, stochastic feasibility and field science are different

- **Computational source witness:** exact K, original source one-hop graph, original energy; SCIP solver status and independent HiGHS primal/dual matching can support computational optimality *for that specific bounded source model*. These are not a formal externally signed certificate or physical feasibility guarantee.
- **Augmented QUBO energy:** adds quadratic squared budget/connectivity penalties and explicit integer binary slack variables; compare to original source objective **only after** independent decoding of original x and verifying true original feasibility. A sufficient P bound is a mathematical objective separation, not a success guarantee for finite-sweep classical SA.
- **Quantum claims:** OpenJij SASampler is **classical** simulated annealing. SQA is historically a notebook configuration placeholder, not validated QAOA, gate-based circuit, actual hardware use or quantum speedup.
- **Physical claim:** source adjacency is modeled from coordinates/hull/current parameters, not validated by lake sensor observations, in-situ water quality, wireless propagation, actual backhaul or station maintainability.
- **Statistical claim:** same seed and same source profile repeated is deterministic replay; **independent parent blocks** are required for inferential comparisons. Two N50/N100 SCIP timings in a single CI environment do not constitute general scaling evidence.

## Source, implementation and publication gates

The verified source hash, original notebook blob hash, feature indices, original weights/factors, K/β/δ, graph type, coefficient binary64 identities, solver execution status and measured timing scopes must be attached to each result. Report **no-incumbent and interrupted** outcomes; retain *every* sampled original and auxiliary state, including infeasible outcomes. New studies must predeclare number of parent blocks, independent child seeds, analysis endpoints, error treatment, stopping rules and multiple-comparison method before observing results. A proposed confirmatory 9,216-read protocol is in [issue #146](https://github.com/carlers/quantum-opt-dashboard/issues/146), **not approved or executed**.

**Software/data/legal controls:** there is no verified root `LICENSE` or `CITATION.cff` on the source branch as reviewed. Repository visibility does not grant redistribution permission over uploaded manuscripts, third-party GeoJSON or dependencies. Confirm copyright, provenance, creator/author names, source-data license, reference publication and archive destination before creating public citation metadata or depositing a public research package. Do not invent a DOI, author citation, funder, site visit, data license or ethics approval.

**Review flow:** preserve originals → derive notebook source cohorts → independently verify solver/witness → repeat in pinned computational environment → archive full raw bytes and SHA manifests → reviewer approves claim level and manuscript discrepancies → only then consider merge, DOI/publication or Streamlit release. A green CI badge is **not** a license, paper parity claim or research sign-off.

## Numerical replay comparability audit — 2026-10-26

A **later source-correct, 72-draw** M2/M3 figure run at [GitHub Actions 40312295092](https://github.com/carlers/quantum-opt-dashboard/actions/runs/40312295092) did **not** reproduce all first-run choices exactly, despite identical parent seeds, child-seed derivation, sweeps, and reported Python/NumPy/OpenJij/SciPy/Shapely versions. Critically, the two runs' **compiled source model fingerprints differed**: original `623821676fc170e68beeb8e83aee28c641f39cbd936ea456b700ea19518f42c2`; later `add84856f0f933eecd4a82b615c239430a85e524d7f00d796c4753f7b4ba4101`. The original notebook row-sum heuristic was `1.0978196676270329` versus `1.097819667627033` (one IEEE-754 binary64 last-place step). Exact `lambda_b/lambda_c`-sensitive QUBO hashes therefore differed on all cells using that heuristic axis, even though source GeoJSON SHA-256 and site ordering remained pinned. Comparing original `samples.csv` against the later artifact at the identical (parent, grid, child-index) keys yielded **10/72 changed full auxiliary bitstrings** and **8/72 changed original site selections**. Cell (row-sum budget, row-sum connectivity) had **4/8 vs 6/8** observed feasible draws; the later one-run grid matrix was `[6,2,0; 2,6,4; 0,2,5]`, versus the first `[4,2,0; 2,6,4; 0,2,5]`.

**This is not evidence that OpenJij disregards a seed under identical exact coefficients**: the source+QUBO binary64 fingerprints already differed. The earlier workflow did not explicitly pin BLAS/OMP thread limits; the later figure workflow did. Thread configuration is a plausible contributor to floating-point reduction differences, but the mechanism has **not** yet been independently isolated or proved. Do not pool or label these two runs as bitwise-exact seed replays or independent stochastic replicate samples of *one strictly identical binary64 optimization problem*.

**Protocol strengthening:** both draft branches now set `OPENBLAS_NUM_THREADS=OMP_NUM_THREADS=MKL_NUM_THREADS=1` for numerical execution where applicable, record these values, retain `compiled_source_model.json` with exact IEEE-754 objective coefficients/graph, and check its digest against the summary before any numerical visualization. Strict bitwise comparability across runner environments remains a separate acceptance condition and must be demonstrated from subsequent artifact pairs, not assumed. Original first-run evidence remains immutable; the new format is additive, not a retrofit to old evidence.

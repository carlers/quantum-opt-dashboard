## Motivation and precise research question

Existing #57 evidence demonstrates that the source-defined GeoJSON, candidate/fixed station ordering, utility numerators/denominators, per-site utilities, pre-interaction linear values, and free–free quadratic terms were identical across particular hosts. **Only four final original-model linear coefficients**, local N20 indices 9, 10, 17 and 19, differed by roughly 1–2×10⁻¹⁶. We therefore ask: which **first recorded operation inside each free-to-existing-station pair's computation** differs across independent host executions, if any, and does the difference appear before or during accumulation into a candidate's final linear coefficient?

This asks for **earliest observed value in source execution order**, not for a proven CPU instruction, compiler behavior, universal last-bit guarantee, or causal attribution to a particular operating system.

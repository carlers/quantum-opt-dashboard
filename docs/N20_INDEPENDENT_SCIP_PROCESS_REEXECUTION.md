## Scientific question and method

The original Streamlit local source mode constructs an exact binary-product MILP from the archived source N20/K5 `Instance`, sends it to SCIP, and saves an **untransformed CPLEX LP** file. Existing scientific checkpoints in PRs #97–#98 verify that the current compiled binary64 model, displayed site selection, mathematical optimum, model/graph/ZIP identity, and **all emitted LP variable domains and linear constraints** match the archived mathematical formulation. However, **a valid LP file on disk does not prove which SCIP binary/process executed it or that any claimed SCIP status/dual bound came from that actual process.**

This experiment tests a strictly **bounded next step**. Its recorded source is the actual, structurally validated LP bytes generated by the first SCIP solve. `scip_lp_reexecution_worker.py` is a **standalone Python program** with no import from original source, Streamlit UI, source model compiler or the scientific witness. A parent in `scip_lp_reexecution.py` writes those exact LP bytes to a temporary file and launches a **new interpreter** with `sys.executable -I`, without shell, to run SCIP's public `Model.readProblem()` and `Model.optimize()` on the *saved* LP file. The worker observes:

- Original emitted LP SHA-256 and byte count; only the exact recorded 20-site x / pair p variable namespace accepted, minimum mathematical problem, bounded LP size and solve-time limit.
- Own fresh SCIP status, feasible solution count, 20 original binary site values and each binary product p value; verifies each p equals its selected two x bits.
- Own SCIP-reported LP-format primal bound, dual bound, relative MIP gap and objective, plus Python/PySCIPOpt version metadata.
- A separate parent-source mathematical checker **re-parses the original LP structurally**, validates the child LP SHA and variable count, re-enumerates the exact original N20 local mathematical feasible region and exact `fractions.Fraction` binary64 original objective, and independently requires both first and second selected solutions to be globally optimal under the current original source model (allowing exactly tied optima). It cross-checks approximate reported SCIP primal/dual convergence and both measured objective displays, while NEVER treating LP decimal serialization as the same bit-exact `float.hex` function.

The original pin is N20, K5, historical one-hop. The separate global **all 15 mandatory original fixed + five new** exploratory geometry network has a different exact enumeration proof and **must not falsely acquire a SCIP global-optimum claim** from this LP-replay. Original geographic all-15-fixed model connectivity remains a mathematical GEOS hull/Euclidean-Dmax proxy, not measured wireless/backhaul.

## What this evidence does NOT authenticate

A child process executing SCIP to read a source-model LP proves that **a local second process was invoked and reported a solve on the supplied LP**, *subject to trusting the same machine, runtime and the emitted process receipt*. It does **not** prove the preceding SCIP process was the one that generated its claimed first solution, does not cryptographically authenticate the SCIP binary or the host OS, does not produce a third-party signed certificate, does not independently replay SCIP's branch-and-bound search tree or prove the integrity of an arbitrary MIP log, and does not protect against adversaries who control the host or entire JSON artifact. The children of these PRs still run in the same GitHub Actions trust boundary. GitHub artifact SHA-256 is a content-integrity checksum with a release/owner-chain provenance, **not a remote attestation signature**. The original SCIP LP is printed with rounded objective decimals (observed 15 significant digits): only the separate original model/score oracle tests bit-exact source objective. LP re-solve differences below the LP printing precision do not justify treating distinct coefficient SHA strings as identical caches.

No historical/authoritative expert AHP sheets, manuscript population/WorldPop vs source D2-road reconciliation, surveyed lake outline, measured RF/antenna/backhaul, DO/current transport or field detection outcome is available in this experiment. Source computation and modeled geometric connectivity do not verify the paper or a real lake-monitoring capability; no quantum advantage claim is supported.

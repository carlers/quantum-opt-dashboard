## What independence means here

PR #66 independently recomputes all 15,504 five-site combinations and hashes the 1,077 feasible sets, **but uses the one-hop flags and free neighbors that the notebook reported**. Both could be wrong together if the notebook's spatial construction were wrong. This audit starts instead with the **original committed 5,417-feature GeoJSON** at SHA-256 `e303cce3d6af6ff4162bb31e09ca27215bc4e29b164fa0181e3f6931de3ae3a7`, reads the actual 15 `has_existing_station` flags, and extracts the existing known ordered 20 candidate source feature positions. No solver or notebook adjacency-array imports are used to **construct** its graph.

1. Independently read and SHA-verify the full original GIS bytes and actual point positions. Compare all 35 resulting original easting/northing coordinates to the notebook's exact emitted `float.hex` positions. Reject candidate identity or actual existing-station changes.
2. Construct the same **deliberately source-specified** GEOS/Shapely **concave hull**, ratio=0.05, `allow_holes=True`, from **all 5,417 original points**. For each possible pair involving a free candidate, require both endpoints and the straight connecting segment be *strictly contained* in the hull, as in the original one-hop semantics. A shoreline boundary point or water-crossing segment does not create a valid original edge.
3. Derive the maximum nearest-existing-to-another-existing distance using stdlib `math.hypot` (not original notebook SciPy KD-tree); multiply by buffer=1.15 to obtain source-derived `D_MAX`. Compare to the notebook's original emitted Dmax within `1e-7` metres. The exact fixed-site flag and segment-predicate decisions themselves must agree; **there is no tolerance when comparing graph membership**.
4. Visit **20×19/2=190** free/free and **20×15=300** free/fixed pairs, skipping fixed/fixed links which cannot enter a new-site one-hop condition. Independently recompute all **190 potential free/free edges** and the 20 fixed-neighbor flags; retain *full local free/fixed link identities*, eligible pair counts, threshold margin and edge counts for independent review.
5. Reject any accepted-water-line pair lying within `1e-7` metres of the Dmax threshold to avoid claiming a stable adjacency classification on an undiagnosed precision boundary. This is a **review guard**, not a scientifically approved global numerical stabilization/rounding policy; it does not change the optimization model.
6. Independently enumerate the feasible space from the **GeoJSON-derived graph**, count **1,077** feasible sets and compare the **complete ordered SHA-256** with the notebook's separate certificate. This must agree exactly, regardless of whether the selected optimum still matches.
7. Archive the complete audited geometry result and the existing fresh-kernel model result separately as GitHub Actions artifacts with short retention (~14 days). The report fingerprints the reconstructed graph evidence, not the original archived notebook's or SCIP source model's math `MODEL_INPUT` digest.

## Adversarial falsification

Synthetic small polygons include a **U-shaped water polygon** whose endpoints are close enough but whose straight line crosses land; an endpoint exactly on the hull boundary; modified *nonselected* free/fixed neighbor flags; altered emitted coordinates; forged spacing; altered feasible SHA; an unsupported source SHA; an invalid threshold and a pair exactly on the distance threshold. These tests must fail when a false original adjacency is claimed. **All actual-lake checks execute cold in CI; no synthetic geometry is represented as the Laguna de Bay output.**

## Scientific limits

This is independently coded and reconstructed from **pinned raw coordinates and source flags** (rather than from the notebook-computed adjacency), with stdlib `math.hypot` in place of NumPy norm for distances. However, **both calculations still rely on the same Shapely/GEOS implementation and the same concave-hull assumption**; this is not an independent hydrological shoreline dataset, separate QGIS raster processing or a proof of water-path navigability. Distinct CPU/BLAS/NumPy ULP differences could still affect borderline classifications; the nearest Dmax-distance margin is recorded to delimit observed safety. The original rule is local one-hop **not global reachability**. All published AHP/D2 and manuscript SCIP energy gaps [#16](https://github.com/carlers/quantum-opt-dashboard/issues/16) remain unresolved; N>20 and stochastic historical OpenJij results require independent references.

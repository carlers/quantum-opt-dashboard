## Four different identities or claims

| Concept | Scientific contract | Permissible inference |
| --- | --- | --- |

| **Exact scored objective identity** | `scripts.science_claim_gate.objective_fingerprint(model)`, exact station/cohort/criterion/weight/float.hex/linear/quadratic + K manifest | A SHA match permits evaluation of mathematical energies under the same score function, **not** same connectivity constraints, site coverage or physical superiority |
| **Observed numerical difference diagnostic** | `scripts.n20_numerical_identity_policy.diagnose_original_n20_objective_pair(a,b)` requires original-looking source cohort, source dataset, N20/K5, exact eight original road-D2/AHP inputs and all **nonlinear/nontrace** input fields unchanged; only original four linear coefficient indices may deviate inside empirical 4/16/2/128-ULP envelope | `observed_posthoc_numerical_envelope_only` is a descriptive observation about these two supplied source-like models, **not mathematical identity, equivalence, certified input provenance, solver optimality or a general-purpose tolerance gate** |
| **Historical scientific/publication or deployment validity** | Original AHP elicitation/GIS D2 reconstruction, measured DO/current/shoreline/RF/backhaul validation, controlled field outcomes, paper source reconciliation | Blocked; no replacement by bitwise closeness, exact SCIP optimum or any cache fingerprint |

## Diagnostic-only policy implementation

`scripts/n20_numerical_identity_policy.py` validates that both supplied input manifests are shaped like the original source N20 study: same original notebook SHA, source data SHA, original candidate and 15 fixed station identities in order, K5, source factor definitions with `d2_road_proximity` and exact eight source weights. It then separately computes **both** exact objective and full input SHA.

Under the **reported study's posthoc observational envelope only**, differing `linear_float64_hex[9]`, `[10]`, `[17]`, `[19]` may show no more than the *observed* 4,16,2,128 integer ULP steps (and absolute 2.220446049250313e-16). Extra changed scoring coefficients, weights, quadratic penalties, dataset, site identities, coordinate inputs, Dmax, hull, solver or connectivity metadata **do not** qualify as that observed drift. The original model's `free_fixed_pair_trace` diagnostic may itself contain the observed intermediate float variation and is excluded from **this observational label only**, not from complete-model SHA/solver cache identity.

The module makes **no claim to independently check raw source GIS/SCIP/S4**, even for equal model inputs. It always returns false for solver-result cache reuse, current solver authentication, manuscript parity and physical monitoring quality. Any genuine UI/solver integration under #88/#91 still requires a separately authenticated source and compiled graph, exact per-run scenario bindings and local/global modeled topology proof.

The source-study accepted numerical tolerance `rel_tol=1e-12,abs_tol=1e-10` is **not a universally safe scientific threshold** and should never silently allow new model/weight/geometry configurations to masquerade as the frozen source. The 4/16/2/128-ULP limits are **observations selected after seeing the data**, so they are not an a priori model-sensitivity budget or error guarantee. In rare near-degenerate combinatorial instances, tiny changes in coefficients can even change the mathematical optimal set; an observed equal original optimum is case-specific, not transferable proof.

## New server-side pre-render boundary

`prototypes/streamlit_water_quality/runtime_attestation.py` is a self-contained scientific **independent mathematical verifier** embedded into the UX branch only. Every new UI solve invokes `attest_current_result()` *before storing a new session result*; it independently reads the actual compiled `model.Instance` and asserts that every complete source model SHA, original 20 free + all 15 fixed station master indices/coordinates, source eight factor weights/meaning, K, Dmax, binary64 `float.hex` linear/quadratic coefficients, one-hop graph and full global source graph are the same as the displayed model and solver inputs. For global mode it reconstructs each adjacency list from independent complete direct graph edge pairs and checks it matches actual model instance source neighbor flags.

Separately, it enumerates up to **C(20,K)≤200,000** selected subsets with a new independently authored local-one-hop or union-find all-15-fixed global feasible graph predicate; scores with **exact integer-scaled rational values of current binary64 coefficients**, not the optimizer's float energy or its reported optimal status. `optimal` and `optimal_exhaustive` require the exact selected mathematical optimum; no tolerance permits a different near-optimal selected subset. Timeout incumbents remain **not proven optimal**, and false `infeasible` is challenged by exact enumeration. This proves a bounded mathematical statement about the *compiled* model, not measured sensor utility.

It rereads the actual local or global ZIP **before** permitting output. Only original local mode can contain a real nonempty `actual_scip_model.lp` byte-identical to what was passed through the current `solve_scip()` optimizer export; global mode must contain `wireless_graph.json` and cannot fabricate a SCIP LP. Every ZIP internal `SHA256SUMS.json`, selected-site CSV index/master ID, stored active model fingerprint, current reported optimizer status and graph edge/graph fingerprint is checked. The resulting attestation record binds the ZIP SHA and original model/graph status/selected bits.

The UI **does not render the selected-site map, selected-site table, solver claims or downloadable result ZIP until this attestation succeeds**. On subsequent Streamlit rerenders `check_visible_result()` verifies the currently compiled model/graph, selected bits, metrics and ZIP bytes against the stored mathematical attestation; on any mismatch the result is **removed from session state**. K, custom AHP weights, D2 meaning (still road), beta, delta, Dmax, topology or site/data changes invalidate the prior model digest and result.

## Mathematical exact-tie, ZIP expansion and status-semantics regression work — 2026-10-20

Further scoped source-only verifier review found three important *general N20 exploratory-setting* failure modes that the original N20/K5 winning-site regression by itself did not exercise. Code and adversarial tests have been added on the unmerged UX-only DRAFT. Do **not** call these latest additions verified until their **final exact-head** CI has passed.

1. **Genuinely tied optimal solutions are valid.** The original integer-scaled exact oracle retains the first lexicographic winning subset only as a convenient witness. It was incorrect to require SCIP or a future exact search to return that same witness when another feasible subset had the **identical exact binary64-derived rational objective**. `exact_selection_objective()` now independently evaluates the actual selected site combination as a `fractions.Fraction` and compares it to the oracle's exact optimum fraction. The selected set need not match its lexicographic witness when the rational scores tie. Conversely, an energy gap of even `2^-40` is not rounded into optimality by the separate **1e-8 reported floating-score consistency tolerance**. New isolated synthetic flat-objective and nearly-tied synthetic test cases exercise this boundary, with genuine SCIP models, but these synthetic objective coefficients are clearly **not original historical source data**.
2. **ZIP archive resources are bounded BEFORE decompression.** Outer compressed bundle size was capped but an adversarial archive may expand to enormous contents. `inspect_archive()` now requires exactly the expected five entries with at most 1,000,000 uncompressed bytes per file and 2,000,000 total. A highly compressible greater-than-1-MB model.json with a tiny outer ZIP must fail **before** JSON/hash parsing. This is limited defensive hardening, not a cryptographic archive signature.
3. **Three mutually distinct exploratory-global result states require their matching proofs.** `infeasible_certified_full_graph_disconnected` needs an independent union-find proof that **the mandatory original 15 existing station vertices remain in different graph components even if ALL 20 candidates are allowed as bridges**; isolated optional candidates alone are irrelevant. `infeasible_certified` must have exhausted all `C(20,K)` and report zero feasible subsets. `time_limit_no_certified_optimum` must have an honest bounded-enumeration solver label and fewer examined combinations than the full search space. A real-source `K=0` counterexample has an infeasible selection even though the 15 mandatory fixed vertices are connectable if other candidates were permitted, and therefore rejects a fake full-graph-disconnected precheck or fake post-exhaustion timeout.

This distinction **does not authenticate a malicious optimizer process or SCIP log**. It improves independent mathematical correctness of a bounded model whose complete instance, selected sites and reported ZIP are passed from the currently compiled backend. No source data, site positions, Dmax, factor definitions, weights or original manuscript were retuned, and no physical lake water-quality conclusions follow.

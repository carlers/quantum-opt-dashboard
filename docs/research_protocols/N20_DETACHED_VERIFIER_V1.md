# Detached N20 research verdict protocol v1 — **unsigned and untrusted demonstration**

**Date:** 2026-10-20. **Review-only child of DRAFT PR #100**, no source notebook/GeoJSON/DOCX edits, no Streamlit deployed UI/backend integration, and no main/preview/production modifications. This is a narrower N20/K5 local source *detached mathematical verifier* prototype, not a hosted verification service and not a new source-authority claim.

## Why this boundary

The original N20 source and its second SCIP-process replay are mathematically checked in PR #100, including first/second one-hop graph feasibility and exact rational score. But these checks run from within the same source/UX checkout and trust one host. In particular, **SHA-256 fingerprints authenticate no author or process**. A signer running with an exported private key on that same compromised host would not solve the problem.

The new `detached_n20_verifier.py` deliberately imports **only Python's standard library plus the independent, pure `scip_lp_structure` bounded LP parser**. It does not import the research model compiler, GeoJSON loader, app, PySCIPOpt, dashboard, or previous process receipt verifier. It can be launched as a separate `python -I` process with its own pre-supplied expected values.

A challenger must provide **three values separate from the submitted evidence envelope**:
1. An unpredictable 32–64 hexadecimal character **expected challenge nonce** (issued before submission).
2. A SHA-256 **source-model commitment** approved independently of the submitted envelope.
3. A SHA-256 **dataset commitment** independently anchored to the original source.

The checker enforces strict version 1 schema, fail-closed non-finite/duplicate JSON/size and foreign-mode controls; checks the exact challenge, commitments and actual emitted LP SHA; reconstructs the original 20 free/15 fixed source site mapping, K=5, eight-factor historical **D2 road proximity**, exact binary64 `float.hex` linear and quadratic coefficients, binary original one-hop neighbor adjacency; and independently parses every original SCIP LP variable, budget, local graph inequality, McCormick product row and SCIP-printed decimal objective.

It independently enumerates all **15,504** possible K5 combinations and calculates the exact source-local valid subset set and optimal score using scaled integer arithmetic on binary64-exact fractions. The historical source oracle should yield **1,077 feasible** subsets and source witness `[0,1,3,6,7]`. It independently validates both first and second reported binary20 vectors (K, feasibility, exact energy, allows genuine exactly tied optima), original status/gap/feasibility labels and second process printed LP objective/primal/dual/gap. All security and paper/physical claim flags MUST remain `false`.

The output is a canonical JSON **unsigned review verdict** binding observed envelope bytes, challenge, external reference commitment, LP digest, feasible-membership SHA, exact rational objective and first/second selected sites. The machine-readable verdict is explicitly labeled `offline_challenge_bound_original_N20_mathematical_review_ONLY`.

## The crucial boundary that remains absent

**No independent source custodian has supplied the commitment in this prototype.** The CI workflow separately generates a challenge, but the example expected source digest is **CO-GENERATED by the same experiment**, and its file literally says `independently_authorized: false`. CI exercises the parser and mathematical checks, not an owner-governed source reference.

No external nonce registry, one-time-use/replay ledger, key rotation, API identity, signature, KMS/HSM, independent solver container/host attestation, or trusted archival custody exists. Calling the checker repeatedly with the **same valid challenge** succeeds: replay consumption is intentionally **not implemented**, and the verdict's `nonce_replay_consumption_enforced_by_service` remains `false`. A hostile host capable of changing BOTH the expected source commitment and the evidence can deceive an offline verifier (an explicit negative **trust-model limitation test**), and even a signature would only certify checks performed by a genuinely independently governed service. No root-of-trust is assumed or simulated.

This is **original local source N20/K5 only**. It does NOT certify the separate global all-15-mandatory-fixed-plus-K graph as a SCIP model, the published manuscript's differing AHP or D2 population/WorldPop narrative, measured RF/backhaul, real DO/current/shoreline/water-quality field outcomes, or quantum advantage. Differences among observed cross-host binary64 coefficient digests `2b238848...` and `8536a3db...` remain distinct strict original source model identities, not interchangeable based on numerical closeness.

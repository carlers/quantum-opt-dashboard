## Preregistered falsifiable hypotheses and primary metrics

- **H0 (no generator effect):** G0 and G1 produce the same 20 original master IDs, original objective coefficients and exact feasible-site membership/optimum.
- **H1 (eligibility effect):** G1 has fewer **zero-degree** selected candidate sites than G0, with an expected zero if G1 successfully chooses 20.
- **H2 (constraint effect):** G1 has more local one-hop-feasible K5 combinations than G0. Because every G1 new candidate is directly fixed-anchored, **mathematics predicts 15,504 / 15,504**; report observed count as validation, not independent scientific improvement.
- **H3 (coverage trade-off):** G1 has a **higher** global nearest-monitor distance (max, and mean) than G0 when computed over **all 5,417 source feature coordinates** to the union of **15 existing stations + the 20 newly generated candidate sites**; measure units metres. Direction unknown before results. Also report distribution using **five optimal selected plus 15 fixed sites** separately; never use 20 generated uninstalled candidates as if deployed sensors.
- **H4 (objective optimum change):** optimal five source master indices differ between G0 and G1. This is a proposed test, not an assumption that the 'better' set scores lower under physically meaningful truth.
